A one-star review of the Moon, written for the Make.fun bounty
"The Moon Gets One Star".

The entry text is 94 characters:

> One star. Advertised as cheese. I brought crackers. It was rock. False advertising since 1969.

`main.py` (Python standard library only) writes that text to
`entry.txt` in the output directory the harness specifies via
`MAKEFUN_OUTPUT_DIR`. The output is deterministic: the same bytes
on every run.
